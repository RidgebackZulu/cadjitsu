Cadjitsu 1.7 lets you **delete bodies**: select one and press Delete. As in Fusion 360, a Remove step joins the timeline, so nothing upstream is lost and undo always brings it back.

## Downloads

| File | For |
|---|---|
| `Cadjitsu-1.7.0-macOS.dmg` | macOS 15 (Sequoia) or later on Apple Silicon |
| `Cadjitsu-1.7.0-Linux-x86_64.tar.gz` | 64-bit Linux with X11 and OpenGL |

**macOS:**
1. Open the dmg and drag Cadjitsu onto Applications.
2. The app is ad-hoc signed, so clear the quarantine flag once:
   `xattr -dr com.apple.quarantine /Applications/Cadjitsu.app`
3. Open Cadjitsu.

**Linux:**
1. Unpack it: `tar xzf Cadjitsu-1.7.0-Linux-x86_64.tar.gz`
2. Run `Cadjitsu-1.7.0-Linux-x86_64/cadjitsu`.

It brings its own Qt and OpenCASCADE; the system only provides X11 and OpenGL. On Debian or Ubuntu, if something is missing: `sudo apt install libgl1 libegl1 libxkbcommon-x11-0 libxcb-cursor0`.

## What's new in 1.7

**Delete bodies**
- **Select and press Delete** (or Backspace): on the canvas (double-click a body, or drag a box round it) or in the browser. Several at once work too.
- **Right-click a body in the browser > Delete** ("Delete 2 Bodies" for a selection), or **Edit > Delete Body**.
- **A Remove step, not lost work.** The body is gone from that point of the timeline on; the features that made it stay. Undo, or delete the Remove step from the timeline, brings it back; suppress the step or roll back before it to see the body again. Features after it, on the other bodies, carry on.
- Inside a sketch, Delete still deletes sketch geometry.

**AI agents (MCP)**
- `delete_bodies {bodies}`: the same Remove step. Use it, not `delete_feature`, to drop one body a feature made among others.
