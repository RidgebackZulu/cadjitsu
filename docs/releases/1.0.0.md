Cadjitsu 1.0 is the first release: parametric CAD for 3D-printable parts, with Fusion 360's workflow and mouse bindings, and an MCP server that lets AI agents model with it.

## Downloads

| File | For |
|---|---|
| `Cadjitsu-1.0.0-macOS.dmg` | macOS 15 (Sequoia) or later on Apple Silicon |
| `Cadjitsu-1.0.0-Linux-x86_64.tar.gz` | 64-bit Linux with X11 and OpenGL |

**macOS:**
1. Open the dmg and drag Cadjitsu onto Applications.
2. The app is ad-hoc signed, so clear the quarantine flag once:
   `xattr -dr com.apple.quarantine /Applications/Cadjitsu.app`
3. Open Cadjitsu.

**Linux:**
1. Unpack it: `tar xzf Cadjitsu-1.0.0-Linux-x86_64.tar.gz`
2. Run `Cadjitsu-1.0.0-Linux-x86_64/cadjitsu`.

It brings its own Qt and OpenCASCADE; the system only provides X11 and OpenGL. On Debian or Ubuntu, if something is missing: `sudo apt install libgl1 libegl1 libxkbcommon-x11-0 libxcb-cursor0`.

## What's in 1.0

**Sketching**
- **Drawing tools:** lines, rectangles, circles, arcs and points, with snapping and heads-up value boxes.
- **Constraints and dimensions:** dimensions become parameters, and the sketch re-solves live.
- **Move / Copy and Offset:** offset draws walls and print clearances.
- **Text:** click and type, choosing the font, size, angle and Reverse (mirrored). Every letter is a region to extrude.

**Modelling**
- **Extrude:** one or two sides, symmetric, to an object or through all, with taper.
- **Fillet, Chamfer, Draft.**
- **Holes:** simple, counterbore, countersink and tapped.
- **Threads:** real helical threads from M5 / #10 up, with print clearance.
- **Mirror, and rectangular and circular patterns.**
- **Combine and Split Body:** split adds alignment pins for parts too big for the bed.
- **Construction planes:** offset and tilted.
- **Emboss Text:** text engraved into or raised from any face, flat or curved. The letters wrap round cylinders, and handles on the canvas move, turn and deepen them.
- **Timeline:** Edit Feature, suppress, rollback and undo, with parameters and expressions.

**Checking and printing**
- **Measure.**
- **Section analysis** with a draggable depth handle.
- **Overhang analysis.**
- **Export:** STL with a watertight / printable check, STEP, and "send to slicer".

**Everyday use**
- **Fusion 360 navigation:** the ViewCube, the marking menu and the navigation bar.
- **Display styles:** shaded, shaded with edges, wireframe and rendered.
- **Units:** mm, cm, m, in and ft, chosen from each value box.

**AI agents (MCP)**
- A built-in MCP server (the glowing MCP button) with tools to sketch, extrude, fillet, drill, thread, pattern, emboss text, measure, take screenshots and export.
- A Claude Code / Hermes plugin and skill with design-for-printing advice.
