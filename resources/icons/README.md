# Cadjitsu icons

The SVGs here are generated by `scripts/icons/gen_icons.py` — edit the script, not the files, then run it:

```
python3 scripts/icons/gen_icons.py            # all icons
python3 scripts/icons/gen_icons.py extrude    # just one
```

CI regenerates them and fails if the committed files differ. `Cadjitsu --selftest=icons --out <dir>` draws contact
sheets (`icons_sheet.png` at 16–48 px, `icons_large.png` at 128 px) to review them.

## Style

- 64 × 64 artboard; each icon is scaled to fill it with a 2 px margin, so every icon reads at 16 px.
- Solids in isometric projection (30°), lit from the upper left: light top faces, mid left faces, dark right faces,
  1.6 px outlines in `#22324A`, a white highlight along the front top edges and a soft contact shadow.
- Palette:

| Role | Colours |
|---|---|
| Body faces (top / left / right) | `#FFFFFF`→`#D5E3F3`, `#C3D6EC`→`#9FBADA`, `#8CAAD0`→`#6687B4` |
| The face or edge being acted on | orange `#FFD58F`→`#FFA63A`, sides `#FFB24E`→`#E77B12` |
| Action arrows | blue `#63A9F7`→`#1B5DC4`, outline `#153F86` |
| Status | green `#6BD77B`→`#1E9A3A`, red `#FF7A6B`→`#CF2A22`, yellow `#FFE07A`→`#F0B429` |

- Sketch tools and constraint glyphs are flat symbols in the accent `#2F7BE0`. The app swaps that exact colour for
  a glyph's state (failed, selected), so use it only where the icon should be recoloured.
- Only SVG features Qt SVG renders: paths, polygons, gradients, opacity. No filters, masks or CSS.
